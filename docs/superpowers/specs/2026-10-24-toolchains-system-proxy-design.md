# 工具链分发与系统代理设计

状态：实现完成，用户已验收；2026-10-24 授权构建并正式发布 v1.2.0

## 目标

让 SerialStudio 在没有预装开发工具的新 Windows 电脑上也能使用常见调试连接；设备专用工具由用户按需下载。网络请求自动遵循 Windows 系统代理设置；未配置代理时使用系统默认路由。安装和卸载由用户掌控，不修改系统 PATH。

设计已由用户确认并授权实施；独立本地候选已验收，按用户最新授权发布 v1.2.0，保留历史 Release。

## 工具链方案

安装包内提供用户确认的必备工具：Android Platform Tools（ADB、fastboot）、OpenSSH Client（ssh、sftp、scp）和 Python 运行时。实现阶段优先核验本机可再分发的二进制来源；缺少、版本不合适或许可不允许随包分发时，改用明确版本的官方分发包，并锁定下载地址、SHA256、许可证及必要运行依赖。不能把 PATH、系统目录或整套开发软件目录整体复制进安装包。

OpenOCD、J-Link、STM32CubeProgrammer、DFU 工具等作为扩展工具目录。用户点击某项的“下载/安装”后才获取；每项显示用途、来源、版本、许可说明和磁盘占用，下载完成校验摘要后再解压/安装。没有确认再分发许可的专有工具不由应用代为分发，改为高级设置选择用户已安装的可执行文件。

工具路径按“高级设置显式路径 → SerialStudio 管理的工具 → 系统 PATH”解析。自动探测只读，不执行烧录或设备写入命令。管理的工具置于独立的每用户数据目录，与应用可执行文件和用户配置分开；程序不修改系统 PATH。

安装器将必备工具随安装包部署到该独立工具目录。卸载程序询问是否保留该目录：保留时移除应用和卸载注册信息但保留工具；移除时只删除清单中由 SerialStudio 管理且路径在该目录内的文件，不删除用户添加的外部文件、用户配置或设备数据。升级沿用原安装目录完整替换应用文件，管理的工具按版本清单迁移/保留，避免每次更新重复下载。

## 系统代理

应用默认自动发现 Windows 系统代理配置，并随系统代理变化生效；系统未配置代理时不强制设置代理，沿用操作系统默认连接。透明 VPN/TUN 加速器由系统网络路由处理。用户不需要在 SerialStudio 再手填一份与系统重复的代理地址。

统一网络策略用于更新检查、Release 下载、扩展工具下载、HTTP 调试和 MQTT。HTTP/MQTT 按相应 Qt 网络接口支持的系统代理类型建立连接；证书验证、主机名验证、超时及下载哈希校验继续生效。更新下载和扩展工具下载不得绕过系统代理裸连。

SSH/SFTP、ADB 等通过外部进程或原始 TCP socket 的连接单独核对系统代理能力。透明 VPN/TUN 情形跟随系统路由；明确代理类型若协议可支持则使用对应方式，否则显示该连接实际未使用系统代理，不能虚报已代理。ADB USB、串口、本机回环等本地链路不经互联网代理。发现系统代理改变时，不在进行中的请求中途切换，后续连接使用新配置。

## 用户体验与错误处理

- 设置页显示“代理来源：系统代理 / 未配置，使用系统默认网络”，并提供只读状态与连通性检查；默认不额外弹窗，也不静默更改 Windows 设置。
- 扩展工具列表区分已安装、可下载、需要用户自行安装三种状态；下载进度可取消。下载中断、摘要不符、空间不足、解压失败时删除本次临时文件并保留已有版本。
- 工具不存在、版本不兼容或启动失败时显示工具名、实际解析到的路径和修复入口，允许选择自定义路径或恢复自动查找。
- 卸载的保留选择在卸载向导中明确呈现；删除操作限定在受管理的工具目录，并按安装清单校验，不递归清理未知路径。

## 验证范围

- 验证工具源、版本、架构、依赖、许可证文本和 SHA256；隔离 PATH 运行 ADB、fastboot、ssh、sftp、scp、Python，并确认不依赖本机开发环境。
- 验证路径优先级、无工具/损坏工具提示、下载中断与错误摘要拒绝安装。
- 使用受控测试代理分别验证系统代理已配置、代理移除后回退默认连接；检查更新、工具下载、HTTP、MQTT 的网络路由。SSH/ADB 按代理协议支持范围单独回归，透明 VPN 与显式系统代理不得混为一谈。
- 验证安装、同目录升级、卸载保留工具、卸载移除工具；检查系统 PATH 和用户配置未被修改或删除。
- 构建和测试完成后报告新增警告/错误。真实设备、用户本机以外的代理环境和发布包由用户验收前不宣称通过。

## 现状依据与待核事项

- 当前更新和 HTTP 调试使用 `QNetworkAccessManager`；MQTT 使用 `QTcpSocket/QSslSocket`；SSH/SFTP 与 ADB 由 `QProcess` 启动。
- 本机 PATH 可见 Windows OpenSSH 9.5.6.2，位于 `C:\Windows\System32\OpenSSH`，同目录有 `LICENSE.txt` 和 `NOTICE.txt`。Python Launcher 指向 Python 3.14，另有 MSYS2 Python。当前未发现 `adb`/`fastboot` 命令或 Android SDK 环境变量；`jlink.exe` 是 Java 工具，不是 SEGGER J-Link。
- 因此不能直接声称用户电脑已具备可打包的所有组件。实现前需核实官方分发源、许可、运行依赖和固定摘要，并保持可复现构建。
